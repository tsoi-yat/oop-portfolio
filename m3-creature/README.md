## 反思

這一站我將原本 M2 只有單一縮殼開關的「硫鐵岩鱗古螺」，重構封裝為 `class LoricataCreature` 物件導向類別，並賦予牠深海懸浮飄遊天性與根據水溫梯度自主切換的「四態行為狀態」（18~45°C 適溫覓食飄遊、低於 10°C 極寒休眠沉底、高於 60°C 噴泉過熱後退趨避，以及雙擊畫面驚嚇縮殼沉底噴發黑煙）。為了營造遼闊深海的生動感，我將實體模型縮小 50% 並移除固定底座，讓古螺在 3D 水體中自主隨機漫遊；同時實作「滑鼠左鍵按住導航」，按住時古螺會即時轉向並加速擺動 60 片硫化鐵甲片與柔性觸角追隨游標游動。
