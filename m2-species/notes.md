# 後未來動物園 M2 物種設定書：硫鐵岩鱗古螺

> **世界觀依據**：天體撞擊後 50,000 年之游離地球（木衛二化冰下大洋系統）  
> **物種學名（推想）**：*Loricata ferrosulfuris*（硫鐵岩鱗古螺）  
> **生態位**：深海黑煙囪基底之初級至次級消費者、化能自營共生體、重金屬沉澱者

---

## 核心生存定案（上台簡報一句話）

> **「在失去太陽的 50,000 年游離冰下大洋，牠藉由體內共生化能菌直接代謝黑煙囪的硫化氫產能，並將致命的熱液重金屬轉化為覆蓋全身的幾何硫化鐵結晶複合重甲，在千米水壓與極酸噴流中建構起移動的礦石堡壘。」**

## 物種設定書五欄（含演化與科學根據）

| 欄位 | 設定內容 | 科學與演化根據 |
| :--- | :--- | :--- |
| **一、型態**<br>(長怎樣、多大) | 外型呈扁平放射狀六角螺丘，成年體長約 **18 ~ 25 公分**。腹足外緣與背甲覆蓋著 **五至六層交錯瓦疊的幾何金屬鱗片**，表面反射出黃鐵礦（愚人金）與磁黃鐵礦的金屬黑金偏光。螺頂中央具備一處**可開闔的微光呼吸排氣孔**，邊緣延伸出多條礦化感溫觸角。 | 真實深海「**鱗角腹足蝸牛** (*Chrysomallon squamiferum*)」演化出由黃鐵礦（$FeS_2$）和膠黃鐵礦（$Fe_3S_4$）組成的三層微米裝甲，外層金屬硬殼能抵抗外力撕扯，中層有機海綿層吸收震波，內層碳酸鈣絕熱防燙。 |
| **二、代謝**<br>(吃什麼、能量來源) | **雙軌化能合成代謝**：<br>1. **共生化能自營**：特化鰓腔囊袋共生高密度硫氧化細菌（$\gamma$-Proteobacteria），直接吸入黑煙囪熱液中的硫化氫（$H_2S$）、甲烷（$CH_4$）與游離鐵離子固定無機碳。<br>2. **刮食齒舌**：口腔內配備磁鐵礦硬化幾丁質齒舌，強力刮食玄武岩壁上附著的厚層硫化菌毯與有機碎屑。 | 加拉巴哥熱泉**巨型管蟲** (*Riftia pachyptila*) 與熱泉螺類體內化能自營代謝機轉；根據 *Christner et al. (2014, Nature)*，冰下環境化能自營產生的有機碳足以支撐 31%~143% 的異營生命繁衍。 |
| **三、繁衍**<br>(怎麼複製自己) | **耐壓包囊卵生（垂直母傳共生菌）**：<br>成體為雌雄同體。每隔數個地熱活動週期，產出外覆幾丁質與硫化鐵礦化硬殼的微型卵鞘（每窩約 60~120 枚），分泌耐高溫矽酸膠質將卵塊牢固鉚釘在黑煙囪背流面的玄武岩裂縫中。<br>母體在排卵時將初代共生菌包覆於卵黃內，幼體在卵內完成金屬甲片初生發育後破殼而出。 | 真實熱泉腹足類多採用保護型底棲硬質卵鞘防止被熱激流沖走；母體親代「垂直傳遞（Vertical transmission）」可確保幼體出生即擁有專屬化能菌種，不需在茫茫深海碰運氣尋覓共生菌。 |
| **四、行為**<br>(天性、怕什麼、追什麼) | **趨熱耐壓、結群固著、警覺縮殼互鎖**：<br>1. **趨熱性**：永遠利用觸角感溫面盤將身體吸附在 15°C~40°C 的最佳熱梯度帶。<br>2. **防禦縮殼**：遭遇水流劇烈擾動或掠食者逼近時，多層幾何鱗片如百葉窗般瞬間收縮扣合，將柔軟腹足完全鎖死在金屬甲殼內。<br>3. **蜂巢群聚**：個體間甲片緊密嵌合排列，共同抵禦強烈熱泉噴流剪力。 | 潮間帶笠螺的緊貼岩壁行為與犰狳/穿山甲的「幾何甲片機械互鎖防禦」；群聚嵌合構造可降低流體阻力 70% 以上，並避免單獨個體被噴泉沖離地熱圈。 |
| **五、威脅**<br>(什麼會殺死牠) | **火山通道偏移熄滅、水壓震爆破甲天敵、過熱噴流燙死**：<br>1. **地熱牢籠拘束**：一旦熱泉噴口斷流或偏移，周遭水溫迅速驟降至 1°C~4°C，體內共生菌斷能，個體進入僵化低溫休眠直至死亡。<br>2. **震爆天敵**：游獵型熱感掠食者具備液壓敲擊螯肢，能強行震碎金屬甲片。<br>3. **突發極熱噴流（>120°C）**：熱泉管壁崩塌時噴出 350°C 沸液導致組織熱變性。 | 地球深海熱泉平均壽命僅數十年至百年，噴口「乾涸與地質位移」是熱泉特化生物最致命的滅絕主因；且深海嗜極酵素在超過 121°C 即會發生不可逆蛋白質變性。 |

## 會動的雛形程式碼（p5.js）

### `sketch.js` 檔案內容
```javascript
// ==========================================
// 後未來動物園 M2 物種雛形：硫鐵岩鱗古螺
// 學名：Loricata ferrosulfuris
// 特徵：幾何黃鐵礦鱗片、呼吸排氣孔、警覺防禦縮殼行為
// ==========================================

let scaleLayers = 4;      // 幾何鱗片層數
let baseRadius = 60;      // 螺體基準半徑
let isAlert = false;      // 是否處於防禦縮殼狀態
let breathTimer = 0;      // 呼吸計時器
let particles = [];       // 黑煙囪硫化物微粒

function setup() {
  createCanvas(600, 600);
  angleMode(RADIANS);

  // 初始化深海微粒
  for (let i = 0; i < 30; i++) {
    particles.push({
      x: random(width),
      y: random(height),
      size: random(1.5, 4),
      speedY: random(-1.2, -0.4),
      alpha: random(50, 150)
    });
  }
}

function draw() {
  // 1. 深海永夜環境（深邃黑藍底）
  background(10, 14, 22);

  // 2. 繪製並更新黑煙囪硫化物上升微粒
  drawSulfurParticles();

  // 3. 計算中心位置與互動狀態
  let cx = width / 2;
  let cy = height / 2;
  let dToMouse = dist(mouseX, mouseY, cx, cy);

  // 互動天性：滑鼠靠近（天敵逼近）時觸發「警覺縮殼防禦」
  if (dToMouse < 160) {
    isAlert = true;
  } else {
    isAlert = false;
  }

  // 4. 計算呼吸脈動（放鬆時平緩起伏，受驚時收緊靜止）
  if (!isAlert) {
    breathTimer += 0.04;
  }
  let breath = sin(breathTimer) * 6; // 正常呼吸擺動 ±6 像素
  let contraction = isAlert ? -12 : 0; // 警戒時甲片內縮緊閉

  // 5. 繪製底部地熱微光溫床
  drawGeothermalBed(cx, cy, breath);

  // 6. 繪製主體：由外而內多層重疊的「幾何硫化鐵結晶鱗片」
  drawPyriteShell(cx, cy, breath + contraction);

  // 7. 繪製中心呼吸孔與熱液排氣流
  drawThermalVent(cx, cy, breath);

  // 8. 狀態文字提示
  drawHUD(isAlert);
}

// 繪製多層六角瓦疊金屬鱗片
function drawPyriteShell(x, y, pulse) {
  push();
  translate(x, y);

  // 外圈感溫礦化觸鬚
  stroke(180, 150, 90, isAlert ? 40 : 120);
  strokeWeight(2);
  let tentacleCount = 12;
  for (let i = 0; i < tentacleCount; i++) {
    let angle = (TWO_PI / tentacleCount) * i + frameCount * 0.005;
    let tLen = isAlert ? 100 : 125 + sin(frameCount * 0.08 + i) * 8;
    line(cos(angle) * 70, sin(angle) * 70, cos(angle) * tLen, sin(angle) * tLen);
  }

  // 由外至內繪製 4 層同心幾何結晶甲片
  for (let layer = scaleLayers; layer >= 1; layer--) {
    let plates = 6 + layer * 2; // 每層的甲片數量
    let r = baseRadius + layer * 22 + pulse * (layer * 0.3);

    // 金屬光澤顏色漸層（模擬黃鐵礦與磁黃鐵礦的金褐交錯光澤）
    let colDark = color(38, 32, 24);
    let colGold = color(195, 155, 80);
    let colEdge = lerpColor(colDark, colGold, layer / scaleLayers);

    for (let i = 0; i < plates; i++) {
      let theta = (TWO_PI / plates) * i + (layer % 2 === 0 ? 0.2 : -0.2);

      push();
      rotate(theta);
      translate(r, 0);

      // 警覺時甲片平貼（旋轉扣合），平時微翹呼吸
      rotate(isAlert ? 0.1 : sin(frameCount * 0.05 + layer) * 0.15 + 0.3);

      stroke(230, 190, 100, 180);
      strokeWeight(1.2);
      fill(colEdge);

      // 繪製六邊形鱗片單元
      beginShape();
      vertex(-12, -8);
      vertex(12, -14);
      vertex(24, 0);
      vertex(14, 14);
      vertex(-10, 12);
      vertex(-16, 0);
      endShape(CLOSE);

      pop();
    }
  }

  pop();
}

// 繪製中央開闔熱液呼吸孔
function drawThermalVent(x, y, pulse) {
  push();
  translate(x, y);
  noStroke();

  // 呼吸孔核心深色外圍
  fill(30, 24, 18);
  ellipse(0, 0, 42, 42);

  // 內壁發光共生菌囊（藍綠化能微光）
  fill(70, 200, 170, isAlert ? 80 : 180);
  let poreSize = isAlert ? 18 : 26 + pulse;
  ellipse(0, 0, poreSize, poreSize);

  // 核心微弱熱點
  fill(255, 230, 180, 230);
  circle(0, 0, 10 + pulse * 0.3);
  pop();
}

// 繪製岩壁地熱光暈
function drawGeothermalBed(x, y, breath) {
  noStroke();
  fill(210, 110, 40, 25);
  ellipse(x, y, 360 + breath * 2, 360 + breath * 2);

  fill(60, 140, 110, 20);
  ellipse(x, y, 280, 280);
}

// 繪製環境飄散微粒
function drawSulfurParticles() {
  noStroke();
  for (let p of particles) {
    fill(210, 180, 110, p.alpha);
    circle(p.x, p.y, p.size);
    p.y += p.speedY;
    if (p.y < 0) {
      p.y = height;
      p.x = random(width);
    }
  }
}

// 介面資訊顯示
function drawHUD(alertMode) {
  fill(180, 190, 200, 200);
  textSize(13);
  textAlign(LEFT, TOP);
  text("物種：硫鐵岩鱗古螺 (Loricata ferrosulfuris)", 20, 20);
  text("生境：黑煙囪外壁 (380 atm / 28°C)", 20, 38);

  if (alertMode) {
    fill(255, 120, 80);
    text("● 狀態：【警覺縮殼互鎖】（感測到天敵或水流震波）", 20, 56);
  } else {
    fill(90, 220, 160);
    text("● 狀態：【舒張代謝】（共生菌吸收硫化物中）", 20, 56);
  }

  fill(140, 150, 160, 140);
  text("※ 嘗試將滑鼠游標移近螺體測試防禦反應", 20, height - 30);
}
```
