# M1 世界

> 10/1（四）上課：世界分享，每個人約三分鐘，形式不限（簡報、草圖、筆記、照片都可以），不用交完整的研究報告。
> 這一站在做什麼、怎麼做、卡住看哪裡，都在課程頁：<https://course.interaction.tw/oop/#milestones>

> 分享的重點是**你自己的想法**：你的世界是什麼樣子（人類消失多久之後、在哪裡、最大的生存挑戰是什麼）、為什麼選這個世界、哪些部分是你自己想出來的，以及查資料或問 AI 的過程中，哪個發現改變了你原本的想法。
> 分享用的東西放進這個資料夾，上台時找得到就好；過程中的材料可以先丟進這個資料夾的 `notes.md`。

把「沒有人類之後」從想像變成你自己的、有根據的世界。
